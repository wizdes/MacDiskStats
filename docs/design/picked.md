# Picked look: B, Quiet native (user, 2026-11-04)

Values live in `docs/design/mockups.html` under `.look-b` and the look `b` entry. Three changes from Astra's critique apply before it becomes the real app:

1. Clearer folder edges and more distinct file type colors, keeping the cushions. Brightness must not outweigh file area.
2. Slightly shorter rows, and stronger contrast for sizes and headers. Names stay readable and numbers stay aligned.
3. The selected path and size stay in the status line after hover ends.
