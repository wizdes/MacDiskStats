Cushion looks

Sample dataFive looks for the same Cushion main window. Every look uses the same made-up disk of about 3,000 files and the same map code; only spacing, type, chrome, map colors and cushion strength change. Hover a box, click a box, a folder row or a file type to try each one.

Pick one of these 5 looks. I recommend B, Quiet native.

Astra (the design advisor) also picked B, with D as runner-up. Before B becomes the real app, I would make 3 changes: clearer folder edges and more distinct file type colors, slightly shorter rows with stronger size numbers, and the selected path staying visible in the status line. Once you pick, I build the app in that look without stopping again.
